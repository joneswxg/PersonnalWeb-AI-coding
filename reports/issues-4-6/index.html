Architecture

代码职责分层

Git-managed contentProfile Data 维护三个精选项目、排除规则与 admitted fork attribution。
GitHub adapters仓库、语言和 commit 请求集中在服务端 source adapter。
Domain modelsProject eligibility、Project Overview、Activity Window 和 Portfolio Home composition 保持纯逻辑可测。
PersistenceDrizzle/PostgreSQL 只保存最新成功 Activity Snapshot，不让失败刷新覆盖有效数据。
Presentation/projects 提供完整目录；/ 提供招聘者导向摘要；/journal 保留文章浏览。

Resilience Contract

GitHub 刷新不是首页可用性的单点故障

  1. 存在 24 小时内快照：直接返回 fresh-snapshot。
  2. 快照过期：尝试刷新仓库、语言和本人提交。
  3. 刷新成功：保存新快照并返回 refreshed。
  4. 刷新失败但存在历史快照：返回 retained-snapshot。
  5. 没有 Token 或从未成功采集：返回 unavailable，首页仍呈现 Git-managed 项目链接。
